# Выполненная локальная проверка

Проверка выполнена 1 ноября 2026 года на Windows, Python 3.12.14.

| Проверка | Наблюдаемый результат |
|---|---|
| Доменные функции, HTTP API и производственные адаптеры | 28 тестов pytest прошли |
| Пять отдельных HTTP-процессов на localhost | Демонстрационный сценарий из 13 шагов прошёл |
| HTTP-коды | Получены ожидаемые 200, 202, 403, 409 и 410 |
| Восстановление | После карантина данные снова читаются |
| Окончательное удаление | Рабочий процесс завершил PURGING → PURGED |
| Аудит | Цепочка прошла проверку, в API появились уведомления |
| Манифесты | 93 ресурса в 10 файлах проверены по строгим JSON-схемам Kubernetes 1.33 |

Локальный HTTP-сценарий использовал SQLite для каталога и данных и локальный перенос outbox. Это проверка реализации и сетевых API, а не запуск PostgreSQL, Cassandra, RabbitMQ, NGINX или Kubernetes. Библиотеки производственных адаптеров установлены, исходные файлы проходят компиляцию Python. Сборка Docker и кластерная демонстрация в этой среде не выполнялись: Docker, kubectl и Minikube отсутствовали.

Полный отчёт реального HTTP-запуска сохраняется командой `python scripts/run_local.py --smoke` в `artifacts/local-smoke.json`; секреты в отчёт не попадают. При запуске GitHub Actions журнал и отчёт появятся в артефакте `verification`. Статус Actions следует смотреть на самом GitHub, он не подставляется в этот документ заранее.

Нагрузочные характеристики, работоспособность NetworkPolicy и отказоустойчивость Cassandra требуют отдельного кластерного эксперимента. Они относятся к главе 4 и пока не заявляются как проверенные результаты.
